# Data-Analytics-SQL-Portfolio
A collection of refactored, enterprise-grade SQL scripts demonstrating database architecture, data hygiene, and multi-schema revenue analytics using MySQL.

### Projects Included:
1. **Revenue & Growth Analysis (`01_revenue_and_growth_analysis.sql`):** Multi-schema analysis utilizing CTEs, window functions (`LAG`), late joins, and subqueries.
2. **Supply Chain Data Hygiene (`02_data_hygiene_and_logistics.sql`):** Data cleaning, string manipulation, and logistics SLA date tracking (`DATEDIFF`).
3. **Relational Database Architecture (`03_relational_schema_and_joins.sql`):** Multi-table inner/left joins, self-referencing employee hierarchies, and regex pattern matching.
